# Help Wanted: Testing Project Planner on MacOS and Linux

I need your help!

Project Planner has been primarily developed and tested on Windows, with some development on Ubuntu Linux, and I want to ensure it works flawlessly on MacOS and other Linux distributions as well. If you're running Obsidian on either of these platforms, I'd love your help testing the plugin and reporting any issues you encounter.

<!-- more -->

## Why I Need Your Help

While Project Planner is built using cross-platform technologies (Electron and TypeScript), there can be subtle differences in how features behave across different operating systems. Things like:

- **File system operations** - Path handling and file creation
- **Keyboard shortcuts** - Modifier keys work differently (Cmd vs Ctrl)
- **UI rendering** - Visual glitches or layout issues
- **Performance** - Memory usage and responsiveness
- **Font rendering** - Text display and sizing

I want to catch and fix these issues early to provide a great experience for all users, regardless of their platform.

## What I'm Looking For

I'm particularly interested in feedback about:

- **Installation process** - Does the plugin install smoothly from the Community Plugins?
- **Core functionality** - Do all views (Board, Grid, Timeline, Dashboard, Dependency Graph) work correctly?
- **Data persistence** - Are your tasks and projects saved properly?
- **UI/UX issues** - Any visual glitches, alignment issues, or rendering problems?
- **Performance** - Does the plugin feel responsive? Any lag or freezing?
- **Error messages** - Are you seeing any error messages in the console?

## How to Help

1. **Install Project Planner** from Obsidian's Community Plugins
2. **Use it for your projects** - The best testing happens through real-world use
3. **Report issues** on our [GitHub Issues page](https://github.com/ArctykDev/obsidian-project-planner/issues)
4. **Share feedback** on what works well and what doesn't

When reporting issues, please include:

- Your operating system and version (e.g., MacOS 14.2, Ubuntu 22.04)
- Obsidian version
- Project Planner version
- Steps to reproduce the issue
- Screenshots or screen recordings if applicable

## Join the Community

Testing isn't just about finding bugs—it's about helping shape the future of Project Planner. Your feedback on features, workflows, and user experience is invaluable.

Check out our [Contributing Guide](../../community/contributing.md) for more ways to get involved, and don't hesitate to share your ideas and suggestions!

Every bug report, feature suggestion, and piece of feedback helps make Project Planner better for everyone. Thank you for being part of this journey and helping me build a truly cross-platform project management solution for Obsidian.
